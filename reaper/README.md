# im4x-chain в REAPER

Два ReaScript-скрипта: выбираете айтем (или несколько), запускаете действие — цепочка
`im4x-chain` обрабатывает активный тейк и показывает этапы в отдельном окне.

| Скрипт | Что делает с файлом | Что делает с проектом |
|---|---|---|
| [`im4x_chain_overwrite.lua`](im4x_chain_overwrite.lua) | перезаписывает исходный WAV/FLAC | перезагружает источник у айтемов |
| [`im4x_chain_copy.lua`](im4x_chain_copy.lua) | пишет копию `<имя>_im4x.wav/.flac` рядом с исходником | добавляет копию новым тейком, оригинальный тейк остаётся |

Оба скрипта используют общий движок [`im4x_chain_core.lua`](im4x_chain_core.lua). Копировать
в папку скриптов REAPER нужно все три файла.

## Что нужно

1. **REAPER 7** (скрипты используют `gfx` и Lua 5.4).
2. **CLI `im4x-chain`** с поддержкой `--progress-file` — это версия из этого репозитория.
   Если CLI уже установлен, обновите его:
   ```sh
   uv tool upgrade im4x-chain
   ```
   Если ставите из локального клона:
   ```sh
   uv tool install --force .
   ```
   Без `--progress-file` скрипты тоже работают, но показывают только «выполняется» и
   общее время, без списка этапов.

Плагины RX 12 (De-plosive, Mouth De-click, Spectral De-noise) должны быть установлены —
их ищет сам CLI, как описано в [основном README](../README.md).

## Установка скриптов

1. Откройте папку ресурсов REAPER:
   - macOS: `~/Library/Application Support/REAPER/Scripts/`
   - Windows: `%APPDATA%\REAPER\Scripts\`
2. Скопируйте туда папку `reaper` (или три `.lua`-файла в одну папку).
3. В REAPER: **Actions → Show action list → New action → Load ReaScript…**
   и выберите сначала `im4x_chain_overwrite.lua`, потом `im4x_chain_copy.lua`.
4. При желании назначьте горячие клавиши или кнопки на панели.

## Как пользоваться

1. Выделите один или несколько айтемов с WAV/FLAC.
2. Запустите действие:
   - **im4x-chain: обработать выбранные айтемы, перезаписав файлы** — с подтверждением,
     потому что файлы на диске меняются безвозвратно;
   - **im4x-chain: обработать выбранные айтемы в копию (без перезаписи)** — оригиналы
     не трогаются.
3. В окне видно: файл, список этапов (чтение, EQ, De-plosive, De-click, De-noise, Leveler,
   компрессор, Loudness, запись), текущий этап, время этапа и общее время. Кнопка
   **Отмена** останавливает процесс; уже обработанные файлы остаются обработанными.
4. В конце:
   - перезапись: источники айтемов перезагружены, REAPER строит новые пики;
   - копия: рядом с исходником появился `*_im4x.wav`, он добавлен новым тейком и активен.
     Переключение тейков — `T` (или Take → Next take).

Обрабатывается **активный тейк** каждого айтема. Если у айтема несколько тейков, остальные
не трогаются.

## Настройки

Все настройки — в начале [`im4x_chain_core.lua`](im4x_chain_core.lua), таблица `CONFIG`.
Их можно переопределить переменными окружения (удобно, если REAPER запускается из терминала).

| Настройка | Переменная | По умолчанию | Смысл |
|---|---|---|---|
| `cli` | `IM4X_CHAIN_CMD` | автоопределение | путь или команда запуска CLI; можно указать `PYTHONPATH=... python -m im4x_chain.cli` |
| `extra_args` | `IM4X_CHAIN_ARGS` | `""` | дополнительные аргументы `im4x-chain process` |
| `copy_suffix` | — | `_im4x` | суффикс имени копии |
| `copy_dir` | `IM4X_CHAIN_COPY_DIR` | `""` = рядом с исходником | папка для копий (относительная — от папки проекта) |
| `confirm_overwrite` | `IM4X_CHAIN_NO_CONFIRM=1` отключает | `true` | спрашивать перед перезаписью |
| `keep_logs` | — | `false` | хранить логи и успешных запусков |

Примеры:

```lua
-- громкость −16 LUFS и потолок −1 dBTP
extra_args = "--target -16 --ceiling -1"

-- только свои этапы, без RX-плагинов (если RX 12 не установлен)
extra_args = "--no-deplosive --no-declick --no-denoise"

-- копии в отдельную папку
copy_dir = "~/Audio/processed"

-- свой путь к CLI
cli = "/Users/me/.local/bin/im4x-chain"
```

`extra_args` — это обычная строка аргументов командной строки. Не добавляйте туда `-o`:
копия сама указывает выходную папку. Остальные ключи (`--eq`, `--reduction`, `--preserve`,
`--comp-*`, `--no-*`) работают как в CLI.

## Где логи

`<папка ресурсов REAPER>/im4x_chain_runs/`. При успешном запуске папка удаляется; при ошибке
или отмене остаётся — в окне есть кнопка **Открыть лог**. Там же `pN.jsonl` с прогрессом и
`pN.log` с выводом CLI.

Одновременно может работать только один процесс: скрипт ставит lock-файл
`<папка ресурсов REAPER>/im4x_chain.lock`. Если REAPER аварийно завершился, следующий запуск
сам уберёт устаревший lock (по PID), но процесс CLI при этом может ещё дорабатывать.

## Ограничения

- Только WAV и FLAC — ровно то, что умеет `im4x-chain`. MP3/AIFF/MIDI, section- и reverse-источники пропускаются с сообщением.
- Скрипт обрабатывает **сам файл**, а не цепочку FX в REAPER. Если на айтеме/треке уже
  висят плагины, они останутся и применятся к уже обработанному звуку.
- Для перезаписи REAPER останавливает воспроизведение, но не закрывает проект. На macOS
  замена файла на лету безопасна; на Windows, если файл занят другим приложением, CLI
  сообщит ошибку, и исходник останется целым (запись идёт через временный файл).
- REAPER Undo отменяет перезагрузку источника/добавление тейка, но **не возвращает**
  перезаписанный файл на диске. Если сомневаетесь — сначала версия «в копию».
- Кнопка **Отмена** и закрытие окна прогресса останавливают процесс. Уже завершённые файлы
  остаются обработанными.
- Перезапись меняет файл, общий для всех проектов/вкладок REAPER. В текущем проекте скрипт
  перезагружает **все** айтемы и тейки, использующие этот файл (включая разрезанные записи),
  а не только выделенные; другие вкладки/проекты останутся со старым звуком в памяти до
  перезагрузки.
- При копировании путь копии добавляется в заметки айтема (Item notes) — там же остаётся
  исходный путь. Громкость, панорама, rate/pitch и start offset тейка переносятся; тейк-FX,
  огибающие тейка и take markers — нет (это новый чистый тейк).

## Если не находится CLI

Скрипт ищет `im4x-chain` в `PATH`, `~/.local/bin`, каталоге uv-tool, `/opt/homebrew/bin`,
`/usr/local/bin` и в локальном чекауте рядом с `reaper/`. Если REAPER запущен из GUI и не
видит `~/.local/bin`, укажите абсолютный путь:

```lua
cli = "/Users/me/.local/bin/im4x-chain"
```

или задайте `IM4X_CHAIN_CMD` в окружении, из которого запускается REAPER. После
`uv tool install` может понадобиться `uv tool update-shell` и перезапуск REAPER.
