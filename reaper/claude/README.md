# im4x-chain в REAPER (версия Claude)

Два действия: выделяете айтемы, запускаете — активный тейк каждого айтема (WAV/FLAC)
проходит цепочку `im4x-chain` в фоне, REAPER при этом не замирает.

| Скрипт | Файл на диске | Проект |
|---|---|---|
| `im4x_claude_overwrite.lua` | исходный файл заменяется результатом (после подтверждения) | все айтемы с этим файлом перезагружаются, пики перестраиваются |
| `im4x_claude_take.lua` | результат пишется рядом: `<имя>_im4x.<ext>` (`_im4x2`, … если занято) | в айтем добавляется новый активный тейк; исходный тейк остаётся (переключение — `T`) |

Общий движок — `im4x_claude_core.lua`, он должен лежать в той же папке.

## Окно прогресса

- имя файла и номер («Файл 2 из 3»), текущий этап («Этап 6 из 11: Spectral De-noise»);
- полоса по файлу: этапы взвешены по их обычной длительности, внутри этапа полоса
  движется по оценке времени (≈ 0.02 с на секунду звука) и не уходит дальше этапа;
- при нескольких файлах — вторая полоса «Всего» (по длине звука);
- **Esc** или закрытие окна — отмена. Процесс убивается до подмены файла, поэтому текущий
  файл не меняется; уже обработанные файлы остаются обработанными.

Этапы видны, если CLI поддерживает `--progress-file`. Со старым CLI окно показывает только
полосу по оценке времени.

## Установка

1. Скопируйте папку `claude` в `~/Library/Application Support/REAPER/Scripts/`.
2. **Actions → Show action list → New action → Load ReaScript…** — выберите
   `im4x_claude_overwrite.lua` и `im4x_claude_take.lua`.

CLI ищется так: путь из ExtState, переменная `IM4X_CHAIN_CLI`, `~/.local/bin`,
`/opt/homebrew/bin`, `/usr/local/bin`, затем `command -v` в login-shell. Свой путь
(например, CLI из клона репозитория) задаётся один раз из консоли ReaScript:

```lua
reaper.SetExtState("im4x_claude", "cli", "/Users/me/im4x-chain/.venv/bin/im4x-chain", true)
```

## Что важно знать

- Файл, который играют несколько айтемов, обрабатывается один раз. При перезаписи меняются
  и невыделенные айтемы с этим файлом — окно подтверждения говорит, сколько их.
- На время обработки айтемы с этим файлом переводятся в offline (при перезаписи).
- Новый тейк наследует offset, playrate, pitch, громкость, панораму и режим каналов
  исходного тейка; FX и огибающие тейка не копируются. Если исходный тейк был секцией
  или реверсом, новый тейк играет файл целиком с тем же offset.
- Добавление тейков отменяется через Undo (одна точка на файл); перезапись файла — нет.
- Только macOS и Linux.
